Pixel bursts

Eight one-off pixel celebrations you fire from an event, like confetti but built from the FooPixel logo's square pixels in two sizes, shading blue to cyan. Click a button to fire from it, or click anywhere in a stage to fire from the pointer. Keys 1–8 fire each one and 0 fires them all. Looking for the hover effects? See the hover demo.

Reduced motion is on for this device, so bursts are skipped.

This page loads dist/foopixel-fx.min.js. Each button calls PixelFX.burst() with the settings above. Without any JavaScript of your own, a data attribute fires a burst on click:

<button data-pixel-burst="confetti">Publish</button>
<button data-pixel-burst="firework" data-pixel-burst-amount="1.5">Upgrade</button>

PixelFX.burst(button, { style: "shatter" });          // from an element
PixelFX.burst({ x: e.clientX, y: e.clientY });        // from a point
PixelFX.burst(button, { style: "rain", scheme: "synthwave" });  // a neon scheme
PixelFX.configure({ scheme: "cyberpunk" });           // every effect and burst

All bursts share one full-page canvas that ignores the mouse. It is added on the first burst and removed once the last pixel has gone. See the README for every option.
