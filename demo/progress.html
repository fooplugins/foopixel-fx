Pixel progress bars

Thirteen progress bars drawn in the FooPixel logo's square pixels, from dist/foopixel-fx-progress.min.js, an optional add-on loaded after the core library. Play a simulated upload (it stalls and spurts like a real one), drag the slider, or make every bar finish or fail. Switch the size to see the same bars at in-app sizes. Looking for the hover effects? See the hover demo or the bursts.

Reduced motion is on for this device, so the bars update without animating.

Wrapping a <progress> beam

The native element stays for screen readers and is the source of truth: this one is driven only by setting progress.value.

HTML only data-pixel-value

No API calls: this bar follows its data-pixel-value and data-pixel-state attributes.

Load the add-on after the core. Any element with data-pixel-progress becomes a bar; give it a height and the pixel size follows.

<script src="foopixel-fx.min.js"></script>
<script src="foopixel-fx-progress.min.js"></script>

<div data-pixel-progress="segments" data-pixel-value="40" data-pixel-label="Upload"></div>
<div data-pixel-progress="beam"><progress value="40" max="100"></progress></div>

const bar = PixelFX.progress(el, "ring", { burst: "confetti" });
bar.set(42);        // 0–100 by default; set(null) for indeterminate
bar.done();         // or reaching max finishes it
bar.fail();
